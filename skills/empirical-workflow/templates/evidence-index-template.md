# Evidence Records

Create one English evidence card per material data source, design choice,
diagnostic, result, or manuscript claim. Start each card from
`<skills_root>/empirical-workflow/templates/evidence-card-template.md`
and use a stable identifier in its filename. Resolve `<skills_root>` from
`workflow.manifest.yaml:canonical_source.skills_root`.

Do not use this index as a second decision log. Decisions belong only in
`decision-log.md`; `_status.md` remains the replaceable current snapshot.
