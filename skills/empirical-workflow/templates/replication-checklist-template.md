# Replication Release Checklist

## Authority and scope

- [ ] Target-journal policy verified from an official URL; URL and `verified_at` recorded.
- [ ] Code root, paper root, immutable source revision, and archive destination recorded.
- [ ] Data licenses, consent, IRB, contracts, confidentiality, and repository restrictions classified.
- [ ] Every restricted input has an approved access route or a complete governed substitute.

## Reproducibility and provenance

- [ ] Master runner and dependency/runtime versions documented.
- [ ] Every table and figure maps to a producing script, line, and output.
- [ ] Raw, analysis, and output data roles are documented; no raw source was overwritten.
- [ ] Required logs, codebooks, preregistration, and materials are present or their omission explained.

## Safety and archive

- [ ] Header, value, free-text, QSF, secret, and absolute-path scans reviewed.
- [ ] Sanitization touched staging copies only.
- [ ] Manifest includes size and SHA-256 for every file.
- [ ] Archive contents, checksum, destination, and release decision independently verified.
