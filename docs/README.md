## Historical and maintenance records

The root [_status.md](../_status.md) describes maintenance of this kit;
[decision-log.md](../decision-log.md) records its decisions. They are not the
state of a new research project. Project attachment creates separate records.

The [evidence directory](evidence/), [designs and plans](superpowers/),
[early trial findings](trial-0815-findings.md), and
[2.8 maintenance summary](workflow-2.8-handoff.md) preserve implementation
history. Dates, test counts, and asset inventories in those records describe
the work at that time, rather than current installation requirements.
In particular, historical journal-template checks refer to locally held assets
that are no longer distributed in the current source tree.
